**Notes for distributors:**
- **psycopg (LGPL-3.0):** used unmodified as a separately installed library, which is generally
  compatible with distributing Apache-2.0 code. `psycopg-binary` wheels bundle `libpq`
  (PostgreSQL Licence) and OpenSSL (Apache-2.0). If you **redistribute a built Docker image**,
  LGPL obligations apply to that image (licence text, ability to replace the library).
  **Decision for v0.1.0-alpha:** Punit does not publish pre-built images. Users build them
  locally from `backend/Dockerfile`, so these obligations do not arise for this repository.
  Revisit this before publishing images to any registry.
- **certifi (MPL-2.0):** unmodified; file-level copyleft applies only if you modify its files.
